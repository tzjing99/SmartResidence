🎉 SmartResidence v0.1.0 — initial public release.

Includes:

- NestJS API with Prisma + Postgres RLS multi-tenancy
- Better Auth (email/OTP, passkeys, 2FA) and CASL-based RBAC
- Resident portal (Next.js) and admin dashboard
- Expo app with resident and guard mode (offline-tolerant)
- Stripe and FPX payment adapters
- Owner-empowerment surfaces: per-unit activity, "who viewed me", instant
  access revocation, itemised fee breakdowns
- Docusaurus documentation with auto-generated API reference
