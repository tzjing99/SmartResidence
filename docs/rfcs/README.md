# Request for Comments

Use an RFC for changes that affect multiple domains, introduce a major
dependency, alter cross-service architecture, or require a significant schema
migration.

## Process

1. Copy an existing RFC or create `NNNN-short-title.md`.
2. Describe the problem, constraints, options considered, chosen approach, and
   migration/rollback plan.
3. Open a pull request and request maintainer review.
4. Record the final decision in the RFC before merging.

Small, reversible implementation changes do not require an RFC.
